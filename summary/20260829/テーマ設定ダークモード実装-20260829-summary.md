# テーマ設定・ダークモード実装 完了要約

## Objective

Settings modal からライト／ダーク／システムを選択できるようにし、全画面の主要配色へ即時反映する。選択値はアプリ固有の browser storage key にだけ保存し、既存のノート保存・更新・バックアップ・削除契約には触れない。

## Scope

| 項目 | 内容 |
|---|---|
| 対象領域 | Settings、テーマ状態、共通配色、ノート紙面と Canvas、終了確認ダイアログ |
| 対象ファイル / ディレクトリ | `src/app/_components/theme/`、Settings、`layout.tsx`、`styles/*.css`、Canvas viewer/runtime、focused Settings test |
| 対象外 | API、Prisma、SQLite、バックアップ保存形式、Desktop bridge、Rust、既存のノート操作契約 |
