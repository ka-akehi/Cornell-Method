# Task Request Template

## Objective

この task で達成する目的を 1〜3 文で記載する。

## Required Inputs

| 種別 | パス | 用途 |
|---|---|---|
|  |  |  |

## Work Instructions

- raw log や長い探索ログを最終回答に含めない。
- 完了時は `summary/task-summary-template.md` の粒度で短く報告する。
- fact、assumption、unknown を分離する。
- 判断に必要な根拠は、ファイル名と見出しまたは行番号で示す。
- 原文全文ではなく、次に読むべき最小箇所を `Next Read` に残す。

## Expected Output

出力先:

```text
summary/YYYYMMDD/HHMM-task-name.md
```

出力形式:

```text
summary/task-summary-template.md
```

## Out Of Scope

- raw log の貼り付け
- 全文ファイルの再掲
- 正本成果物の置き換え
