- Settings shell / bridge、Data and Backup の typed bridge、native file dialog、managed / external restore、pending restore、startup DB recovery、diagnostic export / local log、typed failure、pre-error backup recovery の source 実装と static / disposable 検証がある。packaged GUI、browser、DB read-back を伴う実操作は未検証である。
