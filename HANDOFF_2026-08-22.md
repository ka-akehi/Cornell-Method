## 現在の状態

- MVP Gate 0 は完了済み。現行 Web の route、API、明示保存、確認後の物理削除、詳細画面内の復習、CanvasDocumentV1、legacy Markdown、`/backup` の契約は変更しない。
- Desktop Alpha は全体として未完了である。製品側 `src-tauri/` は作成済みで、user data / SQLite bootstrap、single-instance recovery、既存 primary lifecycle、Settings shell / bridge / entrypoint の部分実装がある。
- 2026-08-21 の UI / Rust 責務抽出と最終 audit は完了した。現時点で追加の責務分割 coding task は不要である。
- Settings は Mac menu と Web gear / mobile trigger の bridge、既存 primary WebView 内の 3カテゴリ modal、focus / keyboard 制御までである。General は読み取り専用、Updates と Data and Backup の操作は未実装で、現行 `/backup` を維持する。

## 完了済みの範囲

### Desktop foundation

- stable `settings/.instance.lock` を authority とする advisory lock、`settings/.instance.owner` の atomic replace、focus socket、bounded retry、stale socket recovery、active / unknown / permission endpoint の fail-safe を実装済み。
- secondary は focus 成功または `AlreadyRunningNotReady` で終了し、Tauri window / sidecar を作らない。primary の ready 後の window 作成、window state、close decision、sidecar / app-owned child process cleanup のコード境界がある。
- dynamic loopback の sidecar ready handshake と cleanup の実装はあるが、実プロセスでの確認は未完了である。

### Settings / responsibility audit

- Mac の Settings menu は新しい window や runtime を作らず、既存 primary WebView へ shared event を送る。
- Web gear / mobile trigger と Mac menu は同じ Settings bridge を使う。modal は General、Updates、Data and Backup の3カテゴリを持つ。
- `main.rs`、Rust lifecycle / runtime / instance module、AppChrome、close coordinator、editor dirty controller、Summary draft controller の責務抽出を完了し、最終 audit は「現時点で追加分割不要」と判定した。

## 既知の検証制約

- 2026-08-21 audit の Desktop contract tests は 15 tests（14 pass、1 skip）。Rust unit test は 21 pass、`cargo fmt --check`、`npm run lint`、`node --check`、`git diff --check` は成功した。lint の既存 warning は残る。
- 1 skip は runner が disposable loopback listener を許可せず、dynamic loopback の sidecar ready handshake を実プロセスで確認できないためである。
- `npx tsc --noEmit` は既存の `src-tauri/target/debug/runtime`、`fabric`、`konva`、`@prisma/adapter-pg` の型解決問題で失敗しており、今回の hook / component 起因の新規エラーではない。
- static contract test の PASS、Rust unit test の PASS、既存 Web / API の証跡を packaged GUI や browser runtime の PASS と扱わない。
